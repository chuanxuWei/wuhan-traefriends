# 周末出逃搭子配对器

让想在同一城市、同一天出门的人，先对上计划，再决定是否交换联系方式。

项目文档：[产品介绍](./intro.md) · [设计说明](./design.md) · [改进计划](./improve.md)

## 目前能做什么

1. 发布真实出逃卡：城市、目的地、日期、时间、主题、节奏、预算、自我介绍与联系平台（微信、小红书、抖音、QQ 或其他社媒）。
2. 按城市和主题浏览有效卡片，发送同行意向。公开列表不返回联系方式。
3. 卡片主人在“我的出逃角落”同意意向后，双方才在各自页面看到对方账号。若双方分别主动表达意向，也会直接配对。
4. 复制卡片分享链接或带话题标签的社媒招募文案、停止招募、删除卡片与全部相关意向。卡片和意向保存在服务器本地 JSON 文件中，服务重启后仍在。

## 本地运行

需要 Node.js 20 或更新版本，无需安装依赖。

```sh
npm start
```

打开 <http://127.0.0.1:4173>。**不要直接以 `file://` 打开 `index.html`**，那个地址不能连接数据服务。

运行验证：

```sh
npm test
```

默认只监听本机。想让其他设备访问，可设置 `HOST=0.0.0.0` 与 `PORT`，并部署到有 HTTPS 和持久化磁盘的服务器。数据文件路径可用 `DATA_FILE` 指定，默认是 `data/store.json`，已加入 `.gitignore`。

## 联系方式与管理口令

- 账号保存在服务端，只有双方同意后通过带管理口令的接口返回给双方。请通过 HTTPS 对外提供服务。
- 浏览器会保存当前卡片的管理口令；换设备时，可在“我的出逃角落”粘贴备份的 64 位口令找回。口令等同管理权限，不能公开分享。
- 分享链接只指向公开卡片，不包含管理口令。
- 删除卡片时，服务器会删除该卡、其联系账号与相关同行意向。服务器或主机的备份需另行管理。

## 上线前仍需处理

当前是可供小范围使用的版本，尚无账号实名核验、举报审核、消息提醒或反垃圾系统。面向公众开放前，需要补上这些能力，并配置 HTTPS、持久化存储、备份和数据处理说明。这里没有接入真实用户池；只有有人实际发布卡片，出逃墙才会出现内容。
